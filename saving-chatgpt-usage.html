한도에 막히지 않고
ChatGPT 오래 쓰기

ChatGPT의 사용량은 한 개의 막대로 설명되지 않습니다. 일반 대화(Chat)의 모델별 한도와, 실제 일을 수행하는 Work·Codex의 공유 한도를 구분하면 필요한 작업에 사용량을 집중할 수 있습니다.

① Chat · 질문하고 생각을 정리하는 곳

Instant / Medium / High / Extra High / Pro 등 선택한 모델과 사고 수준, 요금제에 따라 적용되는 한도가 다릅니다.

위 막대는 구조 설명용 그림입니다. 일반 Chat 전체의 잔여량을 표시하는 공통 막대가 아닙니다.

② Work + Codex · 실제 작업을 수행하는 곳

문서·조사·개발·테스트 등의 작업형 기능은 해당 요금제에서 하나의 사용 허용량과 크레딧 풀을 공유합니다.

위 막대도 설명용입니다. 실제 잔여량과 초기화 시각은 계정의 Usage 화면에서 확인하세요.

Chat: 별도 한도Work: 공유 풀Codex: 공유 풀API Key: 별도 과금

Codex를 ChatGPT 계정으로 로그인해 사용하는 경우와 직접 발급한 API Key로 호출하는 경우는 사용량 체계가 다릅니다.

01

한도는 어떻게 움직이나

모든 ChatGPT 기능이 하나의 5시간·주간 한도를 공유하는 것은 아닙니다.

구분기준기억할 점
일반 Chat요금제·모델·Thinking 수준별공통 잔여량 막대 하나로 설명하기 어렵습니다.
Work·Codex해당 요금제의 공유 허용량Plus 등은 5시간 및 주간 한도가 적용될 수 있습니다.
Pro 100/200/500Work·Codex 포함 허용량현재 Work·Codex 5시간 한도는 없지만 다른 포함 한도는 있습니다.
기업용 계정계약·좌석·관리자 설정일부 Enterprise/Edu 화면에는 월간 크레딧 막대가 있습니다.
도구별 한도파일·이미지·음성 등 별도일반 채팅이 가능해도 특정 도구는 제한될 수 있습니다.
WORK·CODEX 단기 한도5시간 창

해당되는 요금제에서는 짧은 기간에 몰아서 쓰는 작업량을 제한합니다. 이전 창 종료 후 첫 요청에서 새 창이 시작됩니다.

WORK·CODEX 장기 한도주간 허용량

단기 한도가 남아도 주간 허용량이 소진되면 작업을 계속하지 못할 수 있습니다. 계정에 표시된 초기화 시간을 확인합니다.

중요: 월간 사용량 막대는 일부 기업용 크레딧 계정의 표시 방식입니다. 개인 Plus 이용자에게 '모든 사용량이 월간 총량에서 차감된다'고 일반화하면 안 됩니다.
02

모델과 작업의 차이

같은 한 번의 요청이라도 처리할 일이 다르면 사용량이 달라집니다.

OpenAI 공식 추정치. 보장된 메시지 수가 아니며 모델·맥락·추론 설정·도구·작업 복잡도에 따라 달라집니다. 각 행의 횟수를 합산해 쓸 수 있다는 뜻도 아닙니다.

비효율적인 사용

요구사항도 정하지 않고 Work에 “웹사이트를 알아서 완성해 줘”라고 요청하고 반복 수정합니다.

효율적인 사용

Chat에서 목표·화면·검증 기준을 확정한 뒤 Codex 또는 Work에 실행을 맡깁니다.

Chat에서 GPT-6를 선택한 Plus 사용자는 Instant·Medium·High를 사용할 수 있습니다. Extra High·Pro는 Plus에 포함되지 않습니다. Instant가 복잡한 질문을 보고 자동으로 High로 바뀌지는 않습니다(안전 관련 예외 가능).
03

한도에 닿으면 어떻게 되나

모델 전환, 대기, 추가 크레딧, 한도 초기화는 서로 다른 조치입니다.

상황실제 동작
Chat Thinking 한도사용 가능한 다른 모델로 계속 응답할 수 있습니다. 정확한 대체 모델은 상황·요금제에 따라 다릅니다.
Chat Pro 모델 한도다른 모델을 선택하거나 초기화까지 기다립니다. 일부 Pro 요금제는 명시된 자동 대체 모델이 있습니다.
Work·Codex 한도진행 중인 Codex 턴은 공정 사용 범위에서 끝날 수 있습니다. 이후에는 대기·크레딧·초기화 등 계정에 제공되는 선택지를 이용합니다.
한도 소진 후 새 대화새 대화를 열어도 사용량 한도 자체는 초기화되지 않습니다.

“사용 한도 초기화”는 보너스일까요?

서로 다른 세 가지 초기화

  • 정기 초기화: 계정에 정해진 주기에 따라 포함 허용량이 다시 열립니다.
  • 프로모션 초기화: OpenAI가 일부 계정에 자동 또는 보관형(Banked) 초기화를 제공할 수 있습니다. 매번 제공된다는 보장은 없습니다.
  • 유료 Instant Reset: 자격이 되는 개인 Plus/Pro 사용자가 구매하면 해당 한도가 즉시 복원됩니다. 새 주간 기간을 앞당겨 시작하는 것이며 별도 보너스 총량을 더하는 방식이 아닙니다.
오해 바로잡기: 모든 초기화가 '월간 사용량을 미리 당겨 쓰는 것'은 아닙니다. 유료 Instant Reset은 공식적으로 주간 기간을 앞당기는 방식입니다. 프로모션 초기화는 각 행사 조건이 다르므로 같은 방식이라고 단정할 수 없습니다.
핵심

한도 소진 후 모델을 낮춘다고 Work·Codex의 이미 소진한 공유 허용량이 복원되지는 않습니다. 모델 변경은 남은 허용량을 효율적으로 쓰기 위한 선택입니다.

04

긴 대화에서 왜 성능이 떨어질까

사용량 소진과 맥락(Context) 문제를 구분해야 합니다.

원인 후보확인 방법
맥락 창(Context Window)의 제약앞에서 합의한 사항을 놓치거나 오래된 내용을 혼동하는지 살펴봅니다.
새 대화로 이동하며 맥락 누락새 대화에 목표·현재 상태·결정사항·참고 파일을 충분히 전달했는지 확인합니다.
모델·Thinking 설정 변경화면의 모델 선택기와 한도 안내를 확인합니다.
한도 도달 후 대체 모델한도 경고와 표시된 모델·초기화 시각을 확인합니다.
서비스 또는 도구 오류오류 메시지와 OpenAI 상태 페이지를 확인합니다.
공식 사실과 추정을 구분

ChatGPT는 일부 한도에 도달하면 다른 모델로 응답할 수 있습니다. 그러나 답변 품질이 떨어졌다는 느낌만으로 몰래 모델을 낮췄다고 단정할 수는 없습니다. 모델 전환의 모든 내부 판단 기준과 정확한 차감 산식은 공개되어 있지 않습니다.

맥락이 끊기는 예

새 창을 열고 “아까 하던 개발 계속해 줘”라고만 요청합니다.

맥락을 잇는 예

“목표는 ○○, 완료한 일은 △△, 미완료는 □□, 이번에는 이 항목만 검토해 줘.”

새 대화는 복잡하게 누적된 맥락을 정리하는 데 도움이 되지만, 자동으로 성능이 좋아지거나 사용량 한도가 회복되는 것은 아닙니다.

05

절약하는 다섯 습관

질문을 줄이기보다 필요한 작업에 알맞은 모드와 모델을 선택합니다.

1생각은 Chat, 실행은 Work·Codex

기획·토론·요구사항 합의는 Chat에서 먼저 진행하고, 실제 파일 수정·테스트·복합 실행이 필요할 때 작업형 모드로 옮깁니다.

2쉬운 일에는 가벼운 모델

간단한 질문은 Instant, 분석은 Medium/High를 사용합니다. Codex에서는 작업 난도에 따라 Luna·Sol·Astra를 선택합니다. 어려운 일을 무조건 낮은 모델로 반복시키는 것도 낭비일 수 있습니다.

3새 대화에는 인계 요약

주제가 달라지거나 맥락이 복잡해지면 새 대화를 시작하되, 목표·결정사항·진행 상태·남은 작업을 짧게 전달합니다.

4큰 결과물은 설계 확정 후 한 번에

웹페이지·PPT·코드를 먼저 반복 생성하지 말고 목차·기능·검증 기준을 합의한 다음 실행합니다. 캡처·첨부도 필요한 부분만 전달합니다.

5큰 작업 전후로 사용량 확인

Work·Codex의 남은 허용량과 초기화 시간을 보고 중요한 개발·문서 작업을 배치합니다. 한도 초기화는 제공 조건과 유효기간을 확인합니다.

실천

Chat에서 요구사항 정리 → Codex에서 구현 → Chat에서 결과 검토. 단, 실제 파일을 직접 확인해야 하는 검증은 Codex나 Work에 맡깁니다.

06

사용량 확인하기

일반 Chat과 Work·Codex의 사용량 화면은 같지 않을 수 있습니다.

계정 메뉴›Settings(설정)›Usage 또는 Usage & billing

여기서 확인할 것

  • Work·Codex: 남은 허용량, 적용되는 기간, 초기화 시각, 추가 크레딧 및 초기화 옵션.
  • Codex CLI: 실행 중 /status 명령으로 해당 세션의 사용 상태 확인.
  • 일반 Chat: 모델 선택기·한도 안내·표시되는 초기화 시각 확인. 모든 모델을 합산한 공통 잔여 막대가 있다고 가정하지 마세요.
  • Enterprise/Edu 일부: Usage & billing의 월간 사용량·사용 내역·모델별 분석 기능. 일반 Chat 사용량은 Work·Codex 분석에서 제외됩니다.
사용량 표시 기능과 메뉴는 요금제·앱 버전·워크스페이스 설정에 따라 다를 수 있습니다. 예시 막대는 실제 계정의 잔여량이 아닙니다.
직접 해 보기

큰 작업 전 Usage 화면을 확인하고, Codex로 한 가지 명확한 작업을 수행한 뒤 같은 화면에서 변화와 초기화 시간을 비교해 보세요.

07

자주 묻는 것

강연에서 헷갈리기 쉬운 질문을 미리 정리했습니다.

질문답
Chat에서 오래 대화하면 Codex 한도가 줄어드나요?일반 Chat 모델 사용량은 Work·Codex의 공유 허용량과 별도입니다. 단, 실제 Work·Codex 작업을 실행했다면 그 작업은 해당 풀에서 차감됩니다.
Work와 Codex를 번갈아 쓰면 각각 한도를 받나요?아니요. 해당 요금제에서는 공유 허용량을 사용합니다.
한도가 차면 새 채팅으로 우회할 수 있나요?아니요. 새 채팅은 사용량 초기화가 아닙니다.
답변이 나빠지면 모델이 몰래 낮아진 건가요?그것만으로 판단할 수 없습니다. 모델 선택·한도 안내·맥락 누락 여부를 확인하세요.
사용 한도 초기화는 매번 주어지는 보너스인가요?아닙니다. 프로모션 초기화는 자격과 조건이 다르고, 유료 Instant Reset은 주간 기간을 앞당기는 별도 기능입니다.
API Key로 Codex를 쓰면요?ChatGPT 로그인 방식과 달리 API 사용량 및 요금으로 처리됩니다.
한도가 차면 대화가 지워지나요?한도 도달 자체가 대화 기록을 자동 삭제하는 것은 아닙니다.
  • Chat과 Work·Codex의 한도를 구분했다.
  • 모델·Thinking 수준을 작업 난도에 맞췄다.
  • 새 대화로 이동할 때 핵심 맥락을 전달했다.
