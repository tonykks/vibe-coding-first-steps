⚠ 영상을 열면 먼저 화질을 1080p로 바꿔 주세요

화면을 녹화한 영상이라 YouTube가 자동으로 고르는 화질(720p 이하)에서는 글씨가 뭉개져 읽을 수 없습니다. 1080p로 바꾸면 글씨가 또렷하게 보입니다.

화질 바꾸는 방법 (눌러서 보기)
  1. 컴퓨터: 영상을 재생하고 화면 오른쪽 아래 ⚙ 설정 → 화질 → 1080p HD를 누릅니다. 화질 옆에 "자동 (720p)"처럼 보이면 아직 바꾸지 않은 것입니다.
  2. 휴대폰 YouTube 앱: 영상 화면을 한 번 누르고 위쪽 ⚙ → 화질 → 고급 → 1080p를 고릅니다.
  3. 가능하면 전체 화면으로 보세요. 작은 창에서는 글씨가 더 작아집니다.

Claude 데스크톱 앱을 쓰며 생긴 궁금증을 하나씩 묻고 확인한다. Claude md 파일이 꼭 필요한지, Claude Code가 무엇을 할 수 있는지, 내 컴퓨터에서 무엇을 볼 수 있는지 알아보고, 마지막에 강의 사이트를 어떤 기준으로 맞출지 검토를 받는다.

0:00데스크톱 앱도 웹 설정을 쓸까

데스크톱 앱이 웹에서 정한 개인 지침과 메모리를 그대로 쓰는지 확인.

0:08Claude md는 꼭 만들어야 하나

  • 내 요구 폴더마다 Claude md를 꼭 만들어야 하는지 물음.
  • AI의 답 필수가 아니라 그 폴더에서 일할 때의 약속 메모. 이닛 명령으로 초안을 받고 필요할 때 한 줄씩 보태면 된다. Agent md가 이미 있으면 그것을 가리키는 한 줄이면 충분.
  • 알아 두면 좋은 말 Claude md / Agent md는 AI에게 "이 폴더에서는 이렇게 일해"라고 적어 두는 메모 파일. AI가 일을 시작할 때 먼저 읽는다.

0:33협업 Kit를 직접 읽혀 근거 찾기 (핵심 장면 ①)

  • 내가 한 일 예전에 들은 이야기가 맞는지 내 협업 Kit 저장소를 직접 읽어 보라고 함. 폴더를 추가하고 웹 문서 읽기를 허락.
  • AI가 한 일 Github 저장소와 공식 문서를 차례로 읽고, Claude md 파일은 없고 규칙은 Readme에 있다는 사실을 찾아냄. 잘 읽히는지는 /context 명령으로 확인할 수 있다고 알려 줌.
  • 핵심 AI가 말로만 답하지 않고, 내 자료를 직접 읽어 근거를 확인했다.

1:27Claude Code가 하는 일과 확장 장치

  • Claude Code는 파일을 찾고, 고치고, 실행하고, 결과를 보고 다시 고치는 일까지 스스로 하는 Agent.
  • 알아 두면 좋은 말 Skill(자주 하는 작업을 묶어 둔 것), Hook(정해진 때 자동으로 도는 점검), MCP(다른 서비스와 잇는 통로). 처음부터 다 갖출 필요는 없고 불편할 때 하나씩 더한다.

2:10문서 고치고 근거 남기기

  • 내 요구 Agent md를 고치고 왜 그렇게 고쳤는지 Readme에 남겨 달라.
  • AI가 한 일 파일을 고쳐 Github에 올림. 그동안 나는 Github에서 협업 Kit 문서를 열어 Agent별 역할과 승인 절차를 살펴봄.

2:48"원본은 왜 안 고쳤지?" (핵심 장면 ②)

  • 증상 올렸다는데 화면에서 바뀐 곳이 안 보임. 캡처를 보여 주며 되물음.
  • 원인 원본 Kit가 아니라 다른 저장소만 고쳤음.
  • 내가 한 일 근본을 고쳐야 다음부터 적용되지 않느냐고 짚음.
  • AI가 한 일 판단이 틀렸다고 인정하고 원본에도 반영해 올림.
  • 핵심 AI가 "다 했다"고 해도 결과는 사람이 확인해야 한다.

3:28Claude는 내 컴퓨터에서 무엇을 볼 수 있나

폴더 이름은 길을 찾으려고 보이지만, 안의 내용은 내가 허락한 폴더만 열린다.

3:43강의 사이트 표준 검토

  • 내 요구 앞으로 만들 강의 페이지도 같은 모양이 되도록 기준을 세워 달라.
  • AI가 한 일 강의 페이지 18쪽을 비교해, 공통 틀은 잘 지켜졌지만 언어 설정과 디자인 파일이 페이지마다 달라 하나로 묶어야 한다고 정리. 이 결과가 관광대 ③에서 실제로 고치는 출발점이 된다.
