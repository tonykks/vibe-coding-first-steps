⚠ 영상을 열면 먼저 화질을 1080p로 바꿔 주세요

화면을 녹화한 영상이라 YouTube가 자동으로 고르는 화질(720p 이하)에서는 글씨가 뭉개져 읽을 수 없습니다. 1080p로 바꾸면 글씨가 또렷하게 보입니다.

화질 바꾸는 방법 (눌러서 보기)
  1. 컴퓨터: 영상을 재생하고 화면 오른쪽 아래 ⚙ 설정 → 화질 → 1080p HD를 누릅니다. 화질 옆에 "자동 (720p)"처럼 보이면 아직 바꾸지 않은 것입니다.
  2. 휴대폰 YouTube 앱: 영상 화면을 한 번 누르고 위쪽 ⚙ → 화질 → 고급 → 1080p를 고릅니다.
  3. 가능하면 전체 화면으로 보세요. 작은 창에서는 글씨가 더 작아집니다.

0:00웹페이지로 만든 강의 자료 폴더

관광대 강의 자료를 HTML 파일로 만들어 둔 폴더에서 시작.

0:12Github 저장소 만들고 Pages로 배포

  • 내 요구 학생들이 볼 수 있게 인터넷에 올려 달라.
  • AI가 한 일 Github 저장소를 만들고 Github Pages로 배포.
  • 알아 두면 좋은 말 Github Pages는 Github 저장소의 파일을 그대로 웹사이트로 열어 주는 무료 서비스. 배포는 내 컴퓨터의 파일을 누구나 주소로 볼 수 있게 올리는 일.

0:24빈 파일은 공개하지 않기 (핵심 장면)

  • AI가 한 일 내용이 빈 3차시 파일을 스스로 찾아 공개에서 빼고 따로 보관, 계획표에는 "준비 중"으로 표시. 나중에 다시 넣어 봐도 여전히 비어 있어 올리지 않음.
  • 핵심 시키는 대로 다 올리지 않고, 공개하면 안 되는 것을 먼저 걸러 냈다.

0:36종합계획표와 주차별 버튼

6주 동안 컴퓨터 기초, 한글 타자, 아래아 한글 세 과목. 주차별 강의자료 버튼을 누르면 해당 차시 페이지로 바로 이동.

타자 과목 제목 옆에 연습 사이트로 가는 버튼 두 개.

1:24실제 사이트에서 확인하기

Github에 올라간 사이트에서 종합계획표, 한컴타자연습 버튼, 6차시 종합평가 안내를 차례로 확인.
