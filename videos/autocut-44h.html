컴퓨터 이사, 에이전트 팀, 방식 비교처럼 AI와 일하는 방법을 실험합니다.

내 요구AI가 한 일알아 두면 좋은 말핵심

⚠ 영상을 열면 먼저 화질을 1080p로 바꿔 주세요

화면을 녹화한 영상이라 YouTube가 자동으로 고르는 화질(720p 이하)에서는 글씨가 뭉개져 읽을 수 없습니다. 1080p로 바꾸면 글씨가 또렷하게 보입니다.

화질 바꾸는 방법 (눌러서 보기)
  1. 컴퓨터: 영상을 재생하고 화면 오른쪽 아래 ⚙ 설정 → 화질 → 1080p HD를 누릅니다. 화질 옆에 "자동 (720p)"처럼 보이면 아직 바꾸지 않은 것입니다.
  2. 휴대폰 YouTube 앱: 영상 화면을 한 번 누르고 위쪽 ⚙ → 화질 → 고급 → 1080p를 고릅니다.
  3. 가능하면 전체 화면으로 보세요. 작은 창에서는 글씨가 더 작아집니다.

▶ 영상 보기

영상 13편을 만든 강의 녹화본 44시간 19분을 AI에게 컷편집 맡겨 4시간 28분으로 줄인 기록입니다. 멈춘 화면을 자르는 무거운 일은 내 PC의 무료 프로그램(ffmpeg)이 하고, AI는 계획과 판단을 맡았습니다. 사람은 방향을 정하고, 길이표를 보고 승인하고, 결과를 확인했습니다. 세 시간 넘게 걸린 작업을 8분으로 줄여 보여 줍니다.

이 영상으로 전하고 싶은 것

왜 만들었나: 강의 녹화는 대부분 기다리는 시간입니다

AI와 함께 일하는 장면을 녹화하면 화면이 멈춰 있거나 AI의 답을 기다리는 시간이 대부분입니다. 그대로 올리면 보는 사람이 지칩니다. 그 시간을 자르고, 사람이 무엇을 시키고 AI가 무엇을 했는지 보이는 장면만 남기고 싶었습니다.

자동 컷편집 규칙

  • 0.5초마다 화면이 얼마나 바뀌는지 재서 구간마다 처리를 정합니다.
  • 3초 넘게 멈춘 곳은 자르고, 10초 넘게 멈췄으면 멈춘 화면을 2초만 보여 줍니다.
  • 이어지는 빨리 감기는 결과에서 8초를 넘지 않게 합니다.
  • 먼저 길이표를 보고 사람이 승인한 뒤에 영상을 만듭니다.

무거운 일은 내 PC가, 판단은 AI가

렌더링에 두 시간 가까이 걸렸지만 AI 사용량(토큰)은 거의 들지 않았습니다. AI가 44시간 영상을 직접 보는 것이 아니라, 내 PC의 ffmpeg가 만든 숫자로 된 분석 결과만 보고 판단하기 때문입니다. AI Studio의 Build Mode나 클라우드 서버로 하는 방법도 비교했는데, 큰 영상 파일을 올리는 데만 오랜 시간이 걸려, 무거운 처리는 데이터가 있는 내 PC에서 하는 것이 맞았습니다. 웹에서 하는 바이브코딩과 내 PC에서 하는 바이브코딩의 차이가 바로 이것입니다.

이 영상에서 볼 수 있는 바이브 코딩의 방법

  • 사람은 방향과 승인: 코드를 한 줄도 읽지 않았습니다. 무엇을 남기고 싶은지 말하고, 짧은 영상으로 먼저 시험해 결과를 직접 보고, 녹화본 길이표를 확인한 뒤 승인했습니다.
  • 고르는 것은 사람: 더 세게 자르는 안과 흐름을 살리는 안 가운데 어느 것을 고를지는, 그 영상으로 강의할 사람이 정했습니다.
  • 기다리는 일은 사람이 하지 않는다: 렌더링이 도는 동안 사람은 다른 일을 했습니다.

1:00자동 컷편집 규칙

화면 변화로 멈춘 곳을 찾아 자르는 규칙.

  • 알아 두면 좋은 말 ffmpeg는 영상과 소리를 자르고 붙이고 바꾸는 무료 프로그램. 컷편집은 이것과 Python 기본 기능만으로 만들었습니다.

2:45길이표를 보고 승인

44시간 19분이 약 4시간 59분(11%)으로 줄어드는 계획. 가장 긴 13시간 27분짜리는 1시간 24분으로.

5:20토큰을 거의 안 쓰는 이유

무거운 일은 내 PC가, 판단은 AI가. AI Studio Build Mode·클라우드 서버와 비교.

6:50완성

모두 4시간 28분, 3.6GB. 코드 저장은 승인 뒤에.

7:18그다음 단계

  • 알아 두면 좋은 말 srt는 자막 파일(몇 초부터 몇 초까지 어떤 글을 띄울지). TTS는 글을 읽어 주는 음성(이 영상의 목소리). LUFS는 사람 귀에 들리는 소리 크기 단위로, YouTube 기준 -14에 맞춤. 4K로 올리면 YouTube가 자동 화질을 1080p로 잡아 화면 글씨가 읽힘. OAuth는 비밀번호 없이 "이 프로그램이 내 YouTube에 올려도 된다"고 허락하는 열쇠.
