
# Codex 독립 개발 프로젝트 — 한글 글쇠·손가락 기초 연습 프로그램

## 1. 당신의 역할

당신은 이 프로젝트를 단독으로 수행하는 Coding Agent입니다.

나는 Owner이며, 교육 목적과 요구사항을 결정하고 구현 결과를 검수하는 사람입니다.

이번 개발은 Codex 데스크톱 앱의 독립적인 프로그램 개발 능력을 검증하기 위한 실험입니다.

다른 AI Agent와 협업하거나 기존 구현 코드를 복사하지 마세요.

나와 Codex 채팅창에서 직접 대화하면서 기획, 구현, 테스트, 수정을 진행합니다.

기술 선택과 파일 구성은 당신이 판단하되, 아래 교육 목적과 확정 요구사항을 변경하지 마세요.

불명확한 중요한 사항은 추측하지 말고 나에게 질문하세요.

## 3. 프로젝트 목적

한국에 온 외국인 학생들이 한컴타자를 사용하기 전에 한글 두벌식 키보드의 글쇠 위치와 기본 손가락 사용법을 익히도록 돕는 기초 타자연습 프로그램을 개발합니다.

대상은 제주관광대학교 요양보호사 양성과정 유학생 40명입니다.

- 미얀마 학생 39명
- 베트남 학생 1명
- 한국어 능력 TOPIK 1급 수준
- 컴퓨터 키보드 사용 경험이 매우 적은 초보자

이 프로그램은 한컴타자를 대체하는 프로그램이 아닙니다.

동일한 글쇠를 충분히 반복하여 글쇠의 위치와 손가락의 움직임을 몸에 익힌 다음 한컴타자의 자리연습으로 넘어가게 하는 준비 프로그램입니다.

## 4. 가장 중요한 교육 원칙

핵심은 입력 속도가 아니라 올바른 손가락 사용 습관입니다.

음악의 2/4박자에 맞추어 다음 동작을 반복합니다.

쿵: 해당 글쇠를 누릅니다.
짝: 글쇠를 놓고 손가락을 기본 자리로 복귀시킵니다.

모든 손가락은 가능하면 기본 자리를 유지하고, 목표 글쇠를 담당하는 손가락만 움직였다 돌아옵니다.

학생은 직접 글쇠 이름을 소리 내어 말하면서 연습합니다.

프로그램은 실제 손가락을 감지하거나 올바른 손가락을 사용했는지 채점하지 않습니다.

박자의 정확성, 입력 속도, 손가락 복귀 여부도 자동 채점하지 않습니다.

## 5. 연습 진행 방식

1. 학생이 연습 세트를 선택합니다.
2. 해당 세트에서 연습할 글쇠를 직접 선택합니다.
3. 한 번에 하나의 글쇠만 반복 연습합니다.
4. 정답과 오답을 합하여 20회 입력하면 다음 결과 줄 첫 번째 칸으로 자동 이동합니다.
5. Enter 키를 누를 필요가 없습니다.
6. 다음 줄에서도 동일한 글쇠를 계속 연습합니다.
7. 20회, 40회, 60회, 100회 이상 원하는 만큼 반복합니다.
8. 학생이 다른 글쇠를 직접 선택하기 전까지 목표 글쇠를 변경하지 않습니다.
9. 다른 글쇠나 세트를 선택해도 기존 기록은 보존합니다.
10. 자동으로 다른 글쇠나 다음 세트로 이동하지 않습니다.
11. 학생이 종료 버튼을 누를 때 전체 연습을 종료합니다.

잘못 입력한 글자도 한 번의 입력으로 계산합니다.

오답이 발생했다고 20회보다 더 입력하도록 강제하지 않습니다.

## 6. 연습 세트 구성

한글 두벌식의 다음 10개 세트를 구현합니다.

### 1세트: 기본자리 왼손
ㄹ(F), ㅇ(D), ㄴ(S), ㅁ(A)

### 2세트: 기본자리 오른손
ㅓ(J), ㅏ(K), ㅣ(L), ;(Semicolon)

### 3세트: 윗자리 왼손
ㄱ(R), ㄷ(E), ㅈ(W), ㅂ(Q)

### 4세트: 윗자리 오른손
ㅕ(U), ㅑ(I), ㅐ(O), ㅔ(P)

### 5세트: 아랫자리 왼손
ㅍ(V), ㅊ(C), ㅌ(X), ㅋ(Z)

### 6세트: 아랫자리 오른손
ㅡ(M), ,(Comma), .(Period), /(Slash)

### 7세트: 가운데자리 왼쪽 열
ㅎ(G), ㅅ(T), ㅠ(B)

### 8세트: 가운데자리 오른쪽 열
ㅗ(H), ㅛ(Y), ㅜ(N)

### 9세트: Shift + 왼손 윗자리
ㅃ(Q), ㅉ(W), ㄸ(E), ㄲ(R), ㅆ(T)

### 10세트: Shift + 오른손 윗자리
ㅛ(Y), ㅕ(U), ㅑ(I), ㅒ(O), ㅖ(P)

각 세트의 글쇠는 나열된 순서대로 표시하되, 학생이 직접 선택하도록 합니다.

전체 연습 횟수에 제한을 두지 않습니다.

### ㅠ 글쇠의 예외

B(ㅠ)는 한컴타자의 자리연습과 동일하게 왼손 검지로 입력하도록 안내합니다.

두벌식 한글 자판에서는 일반적으로 왼손으로 자음을, 오른손으로 모음을 입력하지만, 자판 배열과 글쇠 배치 때문에 모음인 ㅠ를 왼손으로 누르는 예외가 있다는 점을 설명합니다.

### Shift 동작

왼손 글쇠를 입력할 때는 오른쪽 Shift를 사용합니다.

오른손 글쇠를 입력할 때는 왼쪽 Shift를 사용합니다.

한 글자를 입력할 때의 동작:

1. 반대쪽 Shift를 누릅니다.
2. 다음 박자에 목표 글쇠를 누릅니다.
3. 다음 박자에 누른 글쇠와 Shift를 놓고 모든 손가락을 기본 자리로 돌려놓습니다.
4. 다음 입력에서도 같은 동작을 반복합니다.

Shift를 계속 누른 상태로 여러 글자를 입력하는 방식으로 지도하지 않습니다.

프로그램에서는 실제 목표 글쇠와 올바른 쪽 Shift의 눌림 상태를 함께 확인합니다.

Shift를 누르지 않은 입력이나 잘못된 쪽 Shift를 사용한 입력은 정답으로 처리하지 않습니다.

특히 ㅛ, ㅕ, ㅑ는 Shift를 눌러도 출력 문자가 같으므로 Shift 상태를 반드시 확인해야 합니다.

Shift만 누르는 동작은 연습 횟수에 포함하지 않습니다.

## 7. 화면 구성

컴퓨터 사용이 익숙하지 않은 외국인 학생도 쉽게 이용할 수 있도록 화면을 단순하고 직관적으로 구성합니다.

필수 기능:

- 10개 세트 선택
- 세트별 글쇠 선택
- 현재 연습할 글쇠 표시
- 화면 키보드 표시
- 현재 입력 결과 표시
- 20자 단위 자동 줄바꿈
- 오답 횟수 표시
- 음악 선택 및 재생
- 연습 종료 및 결과 다운로드

### 화면 키보드

실제 한글 두벌식 키보드 배열과 동일하게 표시합니다.

F와 J 글쇠는 항상 고정된 강조색으로 표시합니다.

현재 연습해야 하는 목표 글쇠는 다른 강조색으로 표시합니다.

학생이 실제 키보드에서 글쇠를 누르면 화면의 해당 글쇠가 짧게 아래로 눌리는 듯한 움직임을 표시합니다.

글쇠를 놓으면 원래 위치로 돌아옵니다.

색상은 눈의 피로를 줄이면서 위치를 쉽게 알아볼 수 있도록 선택하세요.

손가락 그림은 사용하지 않습니다.

손가락 이동 애니메이션도 구현하지 않습니다.

### 오답 표시

정답은 정상적인 문자로 표시합니다.

오답은 실제 입력한 문자를 빨간색으로 표시합니다.

오답이 발생할 때 짧은 경고음을 한 번 재생합니다.

오답에 X 표시나 별도의 복잡한 장식을 추가하지 마세요.

## 8. 단계별 안내 및 다국어

학생은 각 연습 단계에 진입할 때 해당 연습의 목적과 사용 방법을 이해할 수 있어야 합니다.

따라서 단계별 안내 페이지 또는 안내 문구를 제공합니다.

안내 언어:

- 한국어
- 미얀마어
- 베트남어

학생은 언어 선택 버튼을 눌러 자신의 모국어로 안내를 확인할 수 있어야 합니다.

번역문은 프로그램에 포함하여 제공합니다.

추후 다음 언어를 추가하기 쉽도록 설계합니다.

- 영어
- 일본어
- 중국어

단, 이번 MVP에서 추가 3개 언어까지 번역할 필요는 없습니다.

학생이 안내를 이해한 후 직접 연습을 시작하도록 합니다.

## 9. 키보드 입력 처리

실제 물리 키보드를 사용합니다.

한글 입력기에서 자모가 자동 조합되거나 입력이 중복 계산되지 않도록 구현해야 합니다.

입력 규칙:

- 한 번 누르고 놓은 글쇠를 한 회 입력으로 계산
- 키를 길게 눌러 발생하는 자동 반복은 중복 계산하지 않음
- 실제 입력한 문자를 결과 칸에 표시
- 오답도 지우지 않고 기록
- Backspace로 이전 입력 결과를 삭제하지 않음
- 20회 입력 후 자동 줄바꿈
- 입력하지 않은 상태에서는 자동 진행하지 않음
- 글쇠 변경 시 이전 기록 보존

한/영 전환키, Backspace, Enter, Caps Lock, Ctrl, Alt, OS 단축키 등의 기본 기능은 별도 수업 교안에서 설명합니다.

이들 키의 사용법을 가르치는 별도 연습 기능은 만들지 마세요.

## 10. 음악 기능

내가 Suno로 제작한 음악을 제공합니다.

음악 파일은 프로젝트의 musics 폴더에 저장합니다.

학생은 제공된 음악 중 원하는 곡을 선택해 재생할 수 있어야 합니다.

음악이 끝나면 자동으로 반복 재생합니다.

음악은 글쇠를 누르고 기본 자리로 돌아오는 리듬을 익히는 데 활용합니다.

음악의 박자와 입력 시점을 프로그램이 정밀하게 동기화할 필요는 없습니다.

학생이 자신의 속도로 연습하도록 합니다.

BPM 입력, 속도 채점, 박자 점수 등의 기능은 구현하지 않습니다.

음악 파일 추가 방법은 README에 간단히 설명합니다.

## 11. 연습 기록과 TXT 결과 파일

연습 기록은 브라우저의 Local Storage에 보존합니다.

### 연습 시작 시각

학생이 첫 번째 글쇠를 실제로 입력한 시각을 자동 기록합니다.

음악을 재생하거나 세트를 선택한 시각은 시작 시각으로 기록하지 않습니다.

### 연습 종료 시각

학생이 종료 버튼을 누른 시각을 자동 기록합니다.

### 기록 유지

학생이 다른 글쇠 또는 다른 세트를 선택하더라도 기존 기록을 보존합니다.

종료 시 모든 글쇠의 입력 결과를 하나의 TXT 파일로 다운로드합니다.

### 파일명

시작 시각을 기준으로 다음 형식을 사용합니다.

YYYYMMDD_HHMM.txt

예:
20261024_1019.txt

### TXT 파일의 내용

- 연습 시작 시각
- 연습한 글쇠별 이름
- 실제 입력한 문자
- 한 줄에 최대 20자
- 각 줄의 오답 횟수
- 연습 종료 시각

예시:

연습 시작 시간: 2026.10.24.10:19

기본글쇠 왼손 "ㄹ"
ㄹㄹㄹㄹㅎㄹㄹㄹㅇㄹㄹㄹㄹㄹㄹㅇㄹㄹㄴㄹ : -4
ㄹㄹㄹㅇㄹㄹㅎㅇㄹㄹㅇㅎㄹㄹㄹㄹㅇㅎㄱㄹ : -8

기본글쇠 왼손 "ㅇ"
ㅇㅇㅇㄹㅇㅇㅇㄴㅇㅇㅇㄷㅇㅇㅇㄹㅇㅇㅇㅇ : -4

연습 종료 시간: 2026.10.24.11:20

위 내용은 출력 형식의 예시이며 실제 연습 데이터는 아닙니다.

한 글쇠를 100회 입력했다면 20자씩 5줄 모두 기록합니다.

20자를 채우지 못하고 종료한 경우에도 마지막 입력 줄을 그대로 보존합니다.

TXT는 글자별 빨간색 표시를 지원하지 않으므로 실제 입력 문자와 오답 횟수로 잘못 입력한 내용을 확인합니다.

브라우저의 다운로드 기능을 이용하여 파일을 저장합니다.

서버나 데이터베이스는 요구하지 않습니다.

## 12. 실행 환경

일반 컴퓨터실의 PC에서 Chrome 브라우저로 웹 주소에 접속하면 바로 실행되어야 합니다.

다음은 필요하지 않습니다.

- 별도 프로그램 설치
- 회원가입
- 로그인
- API Key
- 별도 서버 설정
- 학생용 관리자 계정

이번에는 웹 프로그램만 구현합니다.

모바일 앱은 고려하지 않습니다.

## 13. MVP에 포함하지 않는 기능

## 15. 개발 진행 절차

이번에는 Codex 단독 개발 결과를 확인하려 합니다.

1단계: 이 프롬프트의 요구사항 전체를 읽습니다.

2단계: 로컬 작업 폴더와 현재 파일 상태를 확인합니다.

3단계: 요구사항을 이해한 내용을 요약하고, 구현 방법과 파일 구성을 기획합니다.

4단계: 중요한 충돌 사항이나 반드시 결정해야 하는 사항이 있으면 나에게 질문합니다.

5단계: 기획안을 먼저 채팅창에 간결하게 보고합니다.

6단계: 내가 구현을 승인하면 코딩을 시작합니다.

7단계: 작업 폴더 안에서 프로그램 파일을 직접 생성·수정합니다.

8단계: 로컬에서 실행하고 테스트합니다.

9단계: 검수 기준에 따라 테스트 결과와 미완료 사항을 보고합니다.

10단계: 내가 프로그램을 직접 사용해 보고 피드백을 제공합니다.

11단계: 피드백을 반영해 수정합니다.

12단계: 최종 승인 후 GitHub Push와 웹 배포를 진행합니다.

## 16. 작업과 보고 방식

이번 실험에서 Codex는 단독 Coding Agent입니다.

기획, 구현, 테스트, 수정은 직접 수행하세요.

내가 직접 결정해야 하는 문제가 있을 때만 질문하세요.

기술적인 사소한 선택은 스스로 판단하세요.

승인받은 요구사항을 임의로 변경하지 마세요.

개발이 완료되어도 내 승인 없이 Public GitHub에 Push하거나 웹사이트를 공개 배포하지 마세요.
