## 2. 💻 오프라인에서 더블클릭으로 바로 실행하기
다운로드받은 압축을 푼 폴더에서 **`standalone_timer.html`** 파일을 더블클릭하세요.
- 프로그램 설치 없이 크롬이나 엣지 브라우저에서 바로 열립니다.
- 초대형 노란색 숫자, 1·5·10·20분 프리셋, 마지막 10초 긴급 모드, 종료 캐롤송이 모두 작동합니다.

---

## 3. ❓ 왜 `index.html`을 그냥 더블클릭하면 흰 화면이 나오나요?
`index.html`은 **React & TypeScript (Vite)** 프로젝트의 소스코드 파일입니다.
웹 브라우저는 `.tsx` 확장자의 소스코드를 직접 실행할 수 없으며, 컴퓨터 로컬 파일(`file:///`)로 열 때 보안 정책(CORS)으로 인해 실행을 차단하기 때문에 개발 서버(`npm run dev`) 없이 그냥 열면 빈 화면이 나타납니다.
