내 컴퓨터 안의
AI 두뇌[LM Studio 설치부터 Cline 연결까지]

AI 모델을 내 PC에서 돌리는 LM Studio를 설치하고, Cline 에이전트에 연결해 업무에 써 봅니다. 내 PC 사양으로 어디까지 되는지 솔직하게 확인합니다.

내 요구AI가 한 일알아 두면 좋은 말핵심

⚠ 영상을 열면 먼저 화질을 1080p로 바꿔 주세요

화면을 녹화한 영상이라 YouTube가 자동으로 고르는 화질(720p 이하)에서는 글씨가 뭉개져 읽을 수 없습니다. 1080p로 바꾸면 글씨가 또렷하게 보입니다.

화질 바꾸는 방법 (눌러서 보기)
  1. 컴퓨터: 영상을 재생하고 화면 오른쪽 아래 ⚙ 설정 → 화질 → 1080p HD를 누릅니다. 화질 옆에 "자동 (720p)"처럼 보이면 아직 바꾸지 않은 것입니다.
  2. 휴대폰 YouTube 앱: 영상 화면을 한 번 누르고 위쪽 ⚙ → 화질 → 고급 → 1080p를 고릅니다.
  3. 가능하면 전체 화면으로 보세요. 작은 창에서는 글씨가 더 작아집니다.

내 컴퓨터 안의
AI 두뇌

[LM Studio 설치부터 Cline 연결까지]

▶ 영상 보기

AI 모델을 내 컴퓨터 안에서 돌리는 무료 프로그램 LM Studio를 설치하고, 내 PC에 맞는 모델을 골라 대화하고, 서버를 켜서 VS Code의 Cline 에이전트에 연결했습니다. 작은 7B 모델은 빠르지만 요구를 빠뜨렸고, 큰 30B 모델은 느리지만 한 번에 해냈습니다. 인터넷을 끊고도 Cline이 파일을 만들었지만, 매출채권 연령분석 프로그램은 그래픽 메모리 8GB로는 끝내 완성하지 못했습니다. 틀린 계산을 알아본 것은 업무를 아는 눈이었고, 마지막에는 같은 연령분석의 생각이 공매도 분석으로 옮겨 간 예를 봅니다. (공매도 분석은 투자 추천이 아니라 분석 방법 시연입니다.)

이 영상으로 전하고 싶은 것

AI 두뇌를 내 컴퓨터 안으로 들여올 수 있습니다

LM Studio로 모델을 내 PC에서 돌리면 자료가 밖으로 나가지 않고, 인터넷이 끊겨도 답하고, 사용료도 없습니다. 다만 내 PC의 그래픽 메모리에 맞는 모델을 골라야 합니다.

작은 모델은 빠르고, 큰 모델은 정확합니다

그래픽 메모리 8GB에 다 들어가는 7B 모델은 1초에 50토큰 넘게 답했지만 요구를 자주 빠뜨렸습니다. 일부만 들어가는 30B 모델은 1초에 16토큰으로 느렸지만, 같은 타이머를 한 번에 만들었습니다.

에이전트는 손발, 모델은 두뇌입니다

채팅창은 글로 답만 하고, 저장과 실행은 사람이 합니다. Cursor, Claude Code, Codex의 에이전트는 내 폴더의 파일을 직접 읽고, 만들고, 실행합니다. Cline도 같은 에이전트인데, 두뇌를 내가 고를 수 있어서 내 PC의 LM Studio를 끼울 수 있습니다.

AI가 다 됐다고 해도 확인은 사람의 몫입니다

Cline은 타이머를 다 만들었다고 했지만 요구 하나가 바뀌어 있었습니다. 연령분석 프로그램은 업체별 판매가 아니라 회사 전체 판매로 계산하고 있었습니다. 이런 잘못을 알아본 것은 코드 실력이 아니라 연령분석을 해 본 경험이었습니다.

내 PC 사양의 한계를 솔직하게 봅니다

그래픽 메모리 8GB, 램 32GB로는 Cline과 30B 모델을 함께 쓰기에 부족했습니다. 업무에 제대로 쓰려면 그래픽 메모리 16GB, 넉넉하게는 24GB 이상이 필요합니다. 개인은 클라우드 에이전트에게 자료 없이 규칙만 주고 프로그램을 만들게 하고, 보안이 중요한 회사는 사내 AI 서버에 Cline을 연결하는 길이 현실적입니다.

장면별 자세한 설명

0:00LM Studio란

  • 알아 두면 좋은 말 모델은 AI의 두뇌. LM Studio는 그 두뇌를 내 컴퓨터에서 깨워 일하게 하는 무료 프로그램.

0:24설치

  • 내 요구 LM Studio 설치. 로그인이 필요한지, 사이트 첫 화면의 Bionic을 받아야 하는지 물음.
  • AI가 한 일 Bionic은 같은 회사의 별도 에이전트 프로그램이라 다운로드 페이지 아래쪽의 원래 LM Studio를 받도록 안내. 로그인 없이 설치. 처음 권하는 모델은 건너뛰고, 개발자 모드는 켜고, 컴퓨터를 켤 때 서버가 저절로 켜지는 설정은 끔.

0:36내 PC 사양부터

  • 내가 한 일 작업 관리자의 성능 탭에서 그래픽 메모리와 램을 확인.
  • 알아 두면 좋은 말 그래픽 메모리에 모델이 다 들어가야 빠릅니다. 8GB라면 파일 크기 4~5GB, 곧 7~8B 크기의 4비트 모델이 알맞습니다.

0:50모델 찾기와 받기

  • AI가 한 일 모델 저장 폴더를 여유 있는 드라이브로 바꾸고, Model Search에서 코딩용 모델을 찾도록 안내.
  • 알아 두면 좋은 말 Hugging Face는 전 세계 사람들이 AI 모델을 올려 두는 곳. LM Studio는 모델마다 초록(그래픽 카드에 다 들어감), 파랑(일부만 들어감), 빨강(너무 큼)으로 알려 줍니다. Q4_K_M은 모델을 4비트로 줄인 판 가운데 크기와 품질의 균형이 좋은 것입니다.

1:09불러오기와 컨텍스트

  • 알아 두면 좋은 말 컨텍스트는 AI가 한 번에 기억하는 글의 양. 늘릴수록 메모리를 더 쓰고, 가득 차면 앞의 대화부터 잊습니다.

1:207B: 빠르지만 빠뜨린다

  • 내 요구 매출채권 연령분석이 무엇인지 설명, 10분 타이머 만들기.
  • AI가 한 일 1초에 50토큰으로 빠르게 답했지만 연령분석의 핵심(기간별로 나눈다)을 빠뜨림. 타이머는 시작 버튼을 여러 번 누르면 빨라졌고, 고칠 때마다 전체를 새로 쓰며 다른 곳이 바뀜.

1:4230B: 느리지만 한 번에

  • AI가 한 일 같은 요구를 한 번에 해냄. 대신 1초에 16토큰으로 서너 배 느림. 소리 파일을 인터넷 주소에서 가져오게 만든 것은 사람이 짚음.

1:57서버 켜기

  • 알아 두면 좋은 말 서버를 켜면 이 컴퓨터 안에서만 열리는 주소(127.0.0.1:1234)가 생기고, 다른 프로그램이 그 주소로 내 PC의 두뇌를 씁니다.

2:08Cline이란 · 2:46 연결과 첫 일

  • 내가 한 일 VS Code에 공식 Cline(파란 확인 표시)을 설치하고, 무료 클라우드 대신 "내 API 키 쓰기"를 골라 LM Studio를 연결.
  • AI가 한 일 명령을 실행하기 전에 허락을 구함. 맥용 명령으로 오류가 나자 결과를 읽고 윈도우 명령으로 스스로 바꿈. 비용 0원.

2:59인터넷을 끊고

  • AI가 한 일 인터넷 없이 폴더와 타이머 파일을 직접 만들어 저장. 다 됐다고 했지만 "처음으로" 버튼이 마지막에 고른 시간이 아니라 0분으로 돌아가게 바뀌어 있었음.

3:18업무 시연: 왜 프로그램인가 · 3:40 실패와 업무를 아는 눈

  • 내 요구 9월 말 연령분석 결과표를 정답지로 주고, 같은 결과가 나오는 프로그램을 만들게 함. 규칙(최근 판매월부터 거꾸로 채우기, 마이너스 판매는 앞 달에서 빼기)은 말로 덧붙이고, 인터넷 읽기 권한은 끔.
  • AI가 한 일 긴 파일을 여러 번 새로 쓰다 앞부분을 잃어 실행되지 않았고, 업체별이 아닌 회사 전체 판매로 계산. 사람이 중단하고 실패로 판정.

3:59사양의 한계와 현실적인 길

  • 알아 두면 좋은 말 Cline은 한 번에 1만 토큰이 넘는 안내문을 함께 보냅니다. 그래픽 메모리가 모자란 PC에서는 그것을 읽는 데만 몇 분이 걸립니다.

4:32연령분석에서 공매도로

  • 생각의 줄기: 매출채권 연령분석은 판매가 쌓이고 수금은 오래된 것부터 갚은 것으로 쳐서, 남은 잔액의 나이를 봅니다. 공매도도 같습니다. 날마다 새 공매도가 쌓이고 갚은 것은 오래된 것부터 빼 나가면, 남은 공매도가 평균 얼마에 팔린 것인지 나옵니다. 누가 언제 갚았는지는 공개되지 않아 결과는 가정을 둔 추정치입니다.
  • 화면: 이 평균 단가를 주가와 함께 그린 대시보드. 7월 29일은 주가가 평균 단가보다 가장 크게 낮았던 날, 곧 공매도한 쪽의 추정 이익이 가장 컸던 날입니다.
  • 따라 해 보기: 내가 만든 연령분석 프로그램을 AI에게 보여 주고 "이 매출채권 연령분석 프로그램을 공매도용으로 바꿔 줘. 판매 대신 날마다의 공매도 수량과 금액, 수금 대신 갚은 수량으로 계산해 줘."라고 해 보세요.
  • 이것은 투자 추천이 아니라, 분석 방법을 보여 드리는 시연입니다.
