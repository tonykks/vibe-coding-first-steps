⚠ 영상을 열면 먼저 화질을 1080p로 바꿔 주세요

화면을 녹화한 영상이라 YouTube가 자동으로 고르는 화질(720p 이하)에서는 글씨가 뭉개져 읽을 수 없습니다. 1080p로 바꾸면 글씨가 또렷하게 보입니다.

화질 바꾸는 방법 (눌러서 보기)
  1. 컴퓨터: 영상을 재생하고 화면 오른쪽 아래 ⚙ 설정 → 화질 → 1080p HD를 누릅니다. 화질 옆에 "자동 (720p)"처럼 보이면 아직 바꾸지 않은 것입니다.
  2. 휴대폰 YouTube 앱: 영상 화면을 한 번 누르고 위쪽 ⚙ → 화질 → 고급 → 1080p를 고릅니다.
  3. 가능하면 전체 화면으로 보세요. 작은 창에서는 글씨가 더 작아집니다.

0:00같은 과제, 두 방식

원고 파일과 디자인 견본을 주고 견본 모양의 강의 페이지를 만들게 함.

  • 대화 방식: 원고를 빠짐없이 옮김. Code 방식: 내 컴퓨터 폴더에서 바로 읽고 쓰며 휴대폰 화면까지 직접 확인.

4:00결국 둘 다 클라우드에서 생각하는데 왜 다를까 (핵심 장면 ①)

  • 답 생각(AI 모델)은 둘 다 클라우드. 실행은 대화 방식이 클라우드의 임시 작업 공간(리눅스), Code 방식이 내 Windows 컴퓨터.
  • 알아 두면 좋은 말 샌드박스는 클라우드에 잠깐 만들어지는 격리된 작업 공간. 작업이 끝나면 사라진다.

5:24프로그램을 저장해 두면? (핵심 장면 ②)

  • 내 가설 매번 AI에게 다시 만들게 하지 말고, 만드는 프로그램을 저장해 두고 돌리기만 하면 된다.
  • 실험 결과 두 방식 모두 Python 변환 프로그램을 만들었고, 저장한 프로그램은 실행할 때 토큰 0, 두 번 돌려도 한 글자도 다르지 않음.
  • 알아 두면 좋은 말 토큰은 AI가 읽고 쓰는 글자 조각 단위. 사용량과 비용의 기준.

13:36반복 작업이면 프로그램을 키우자

같은 형식 작업이 두세 번만 반복돼도 프로그램 방식이 손익분기를 넘는다는 계산. 강의 10개로 확인할 실험 설계.
