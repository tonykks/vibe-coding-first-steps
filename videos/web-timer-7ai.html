내 요구AI가 한 일알아 두면 좋은 말핵심

⚠ 영상을 열면 먼저 화질을 1080p로 바꿔 주세요

화면을 녹화한 영상이라 YouTube가 자동으로 고르는 화질(720p 이하)에서는 글씨가 뭉개져 읽을 수 없습니다. 1080p로 바꾸면 글씨가 또렷하게 보입니다.

화질 바꾸는 방법 (눌러서 보기)
  1. 컴퓨터: 영상을 재생하고 화면 오른쪽 아래 ⚙ 설정 → 화질 → 1080p HD를 누릅니다. 화질 옆에 "자동 (720p)"처럼 보이면 아직 바꾸지 않은 것입니다.
  2. 휴대폰 YouTube 앱: 영상 화면을 한 번 누르고 위쪽 ⚙ → 화질 → 고급 → 1080p를 고릅니다.
  3. 가능하면 전체 화면으로 보세요. 작은 창에서는 글씨가 더 작아집니다.

▶ 영상 보기

"10분 타이머 만들어 줘" 한 줄로 시작해, 같은 타이머를 ChatGPT(채팅·Work·Codex), Claude(채팅·Code), Gemini, Google AI Studio(Playground·Build mode)에서 만들어 비교했습니다. 웹 채팅창은 말로 다 만들어 주지만 조금만 고쳐도 코드 전체를 다시 쓰고, 그러다 멀쩡하던 곳이 깨지기도 합니다. 고장은 사람이 화면을 보고 찾았고, AI가 내놓은 원인 설명이 틀린 때도 있었습니다. 마지막에는 만든 것을 내려받고, 공유하고, 배포하고, 다시 내려 보며 "남의 서비스에 올린 것은 언젠가 없어질 수 있으니 파일로 받아 내 것으로 만들어 두어야 한다"는 것을 확인합니다.

이 영상으로 전하고 싶은 것

웹 채팅창은 말로 다 만들어 줍니다

"10분 타이머 만들어 줘" 한 줄만 넣어도 어느 AI든 돌아가는 타이머를 내놓습니다. 시작·일시정지·알림음처럼 말하지 않은 것까지 알아서 넣습니다. 처음 만들어 보기에는 웹 채팅창으로 충분합니다.

그런데 조금만 고쳐도 전체를 다시 씁니다

숫자 색 하나를 바꿔 달라 해도 웹 채팅창은 코드 전체를 처음부터 다시 씁니다. ChatGPT는 스스로 "통째로 교체해서 쓰시면 됩니다"라고 말했고, Gemini는 다시 쓰다가 앞부분을 빠뜨려 화면에 꾸밈 코드가 글자로 찍혀 나왔습니다. 반대로 Codex와 AI Studio Build mode는 바뀐 파일과 줄만 고쳤습니다.

고장도, 틀린 설명도 사람이 찾았습니다

배경이 안 보이자 AI는 "방화벽이나 보안 때문"이라고 설명했지만, 실제로는 없는 사진 주소를 넣은 것이었습니다. 그럴듯한 설명이 틀릴 수 있으니, 결과는 직접 열어 보고 시험해야 합니다.

남의 서비스에 올린 것은 내 것이 아닙니다

AI가 올려 준 주소는 로그인해야 열리거나, 언제 없어질지 모릅니다. Codex는 스스로 "영원히 유지된다고 생각하시면 안 됩니다"라고 했고, 배포를 내리자 주소는 바로 사라졌습니다. 오래 쓸 것은 파일로 받아 내 컴퓨터에서 열리는지 확인하고, 필요하면 내 계정의 배포처에 올려 내 것으로 만들어 두어야 합니다.

장면별 자세한 설명

0:00ChatGPT 채팅

  • 내 요구 "10분 타이머 만들어 줘." 이어서 숫자 크기·색, 시간 버튼·마지막 10초·알림음, 계절 배경, 내려받기.
  • AI가 한 일 채팅 안에서 바로 돌아가는 타이머. 두 가지만 고쳐 달라 해도 "아래 코드로 통째로 교체해서 쓰시면 됩니다". 계절 배경은 처음에 눈사람 그림 한 장을 그렸다가, 다시 코드로 그린 늦가을 풍경으로. 마지막에 HTML 파일 하나(59줄).

3:24ChatGPT Work 모드

  • AI가 한 일 새로 만들지 않고, 라이브러리에 있던 채팅 모드 결과 파일을 그대로 열어 줌. 비교에서 뺐습니다.

4:12ChatGPT Codex

  • 내 요구 같은 한 줄 → 수업에 쓸 타이머라고 덧붙임.
  • AI가 한 일 처음에는 "10분 뒤 알림 예약"으로 알아들음. 바뀐 파일과 줄 수만 보여 주며 고침. 은행잎·단풍 그림을 직접 만들고, 결과를 인터넷 주소로 올림(본인만 열림). ZIP과 HTML 파일 하나를 함께 줌.
  • 알아 두면 좋은 말 배포는 내 컴퓨터의 파일을 다른 사람도 여는 인터넷 주소로 올리는 일.

7:00Claude 채팅 · 8:48 Claude Code

  • AI가 한 일 같은 한 줄에 시작·일시정지·처음으로가 든 타이머. 늦가을 밤 배경을 코드로 그리면서 "숫자 크기를 조금 줄였다"고 스스로 밝힘. Claude Code는 낙엽이 떨어지는 배경을 만들고, 링크만 있으면 누구나 여는 주소로 공유.

10:36Gemini 채팅

  • AI가 한 일 숫자 크기와 색만 바꿔 달라 했는데 단축키·진행률·화면 깜빡임까지 더함. 다시 쓰다가 미리보기에 꾸밈 코드가 글자로 찍히는 고장, 배경 그림이 안 보이는 고장. 사람이 화면을 보고 알려 주자 고침.

15:36AI Studio Playground

  • 내 요구 일곱 가지 요구를 한 번에.
  • AI가 한 일 숫자와 버튼은 다 됐지만 배경이 안 보임. 원인을 방화벽·보안 탓으로 설명했지만, 실제로는 없는 사진 주소. 고친 판은 그림을 코드로 그림.

17:31AI Studio Build mode

  • AI가 한 일 파일을 여러 개로 나눈 프로젝트, 배경 사진을 직접 만들어 넣음, 설정 화면까지. 추가 요구(끝날 때 크리스마스 캐럴)는 바뀌어야 할 파일만 골라 고침.
  • 알아 두면 좋은 말 React 프로젝트는 여러 부품 파일을 도구로 조립해야 돌아가는 형태. 그래서 내려받은 index.html을 더블클릭하면 빈 화면이 나옵니다.

21:16내려받은 파일이 빈 화면일 때

  • 내 요구 빈 화면을 고쳐 달라 → 받은 파일에 일부 기능만 있어 다시 요구.
  • AI가 한 일 더블클릭으로 여는 파일 하나를 따로 만들고, 다시 요구하자 그제야 모든 기능을 담은 파일을 줌. 나뉜 파일은 "설계도와 부품", 하나로 묶은 파일은 "시동만 걸면 되는 완성차"라고 비유.

24:19Share와 Publish

  • 내가 한 일 공유 범위를 정하고, 결제 계정이 연결된 프로젝트를 고르고, 주소 이름을 정함. 처음이라 옆에 다른 AI를 열어 단계마다 물어 가며 진행.
  • AI가 한 일 Share는 Google에 로그인한 사람만 볼 수 있음. Publish는 결제 계정이 없으면 "No billing setup"에서 멈추고, 있으면 몇 분 만에 누구나 여는 주소로 빌드·배포. 배포를 내리자 같은 주소는 "Page not found".
  • 알아 두면 좋은 말 결제 계정(billing)은 클라우드에 올린 앱이 쓴 만큼 요금을 내는 연결. 작은 앱은 무료 사용량 안에서 0원에 가깝지만, 켜 둔 동안은 비용이 생길 수 있습니다.
