10:20영상 준비 중

강연 주제 "나만의 코딩 에이전트 만들기"의 출발점이다. Google의 Antigravity IDE 하나에 AI 여섯이 일할 자리를 만들고 이름과 역할을 준다. IDE 안의 지니, 옆 창의 행크(Codex)와 버디(Claude Code), 터미널의 애니·토디·제리. 설치는 Claude 데스크톱 앱의 토비가 화면 캡처를 보고 한 단계씩 안내하고, 사람(Owner)은 결정과 클릭, 로그인만 한다.

0:00AI 여섯의 자리 만들기

  • 목표: Antigravity IDE 하나 안에서 여러 AI가 역할을 나눠 일하게 하기.
  • 알아 두면 좋은 말
    • IDE: 코드를 쓰고 실행하는 작업 프로그램. Antigravity는 Google이 만든 AI 중심 IDE.
    • 확장 프로그램: IDE에 기능을 더하는 추가 부품. 여기서는 Codex와 Claude Code를 IDE 옆 창으로 넣는다.
    • CLI(명령 도구): 같은 AI를 터미널에서 글자 명령으로 부르는 버전.

0:22토비에게 설치 안내 맡기기

  • 내가 한 일 화면을 캡처해 Claude 데스크톱 앱(토비)에 보냄. 버튼은 직접 누름.
  • AI가 한 일 캡처를 보고 "다음은 이 버튼"을 알려 줌. 비슷한 이름의 다른 앱이 아니라 독립 실행형(Standalone) IDE를 받으라고 짚어 줌.
  • 핵심 AI는 화면을 보고 안내하고, 실제 클릭과 로그인은 사람이 한다. 이 역할 나누기가 끝까지 이어진다.

1:36Google 로그인과 첫 설정

  • 화면 색, 에이전트 작업 방식, 함께 쓸 Google 도구, 보안 안내를 차례로 고름.
  • 2:12 에이전트 방식: "중요한 단계마다 내가 검토"(Review-driven)를 고름. 토비가 네 가지 차이를 설명.

2:55행크: Codex 확장 프로그램

  • 내가 한 일 "codex" 검색, 설치, ChatGPT 계정으로 로그인.
  • AI가 한 일 이름이 비슷한 확장 프로그램 중 게시자(openai)와 다운로드 수로 공식 제품을 가려 줌.
  • 알아 두면 좋은 말 Codex는 내 ChatGPT 요금제 한도를 쓴다.

4:48버디: Claude Code 확장 프로그램

  • 내가 한 일 같은 방법으로 설치, Anthropic 게시자 확인, 브라우저에서 Claude 계정 승인.
  • 정리 기본 에이전트 지니까지 IDE 안에 AI가 셋이 된다.

6:23애니·토디·제리: 터미널 명령 도구 세 개

  • 내가 한 일 토비가 준 공식 설치 명령을 터미널에 붙여 넣고 결과를 캡처.
  • AI가 한 일 빨간 경고 글자가 실제 오류가 아니라고 풀어 주고, 경로 등록 명령과 세 도구 버전 확인 명령(agy --version; codex --version; claude --version)을 만들어 줌.
  • 알아 두면 좋은 말 경로(PATH) 등록은 프로그램 이름만 쳐도 어느 폴더에서나 실행되게 컴퓨터에 위치를 알려 두는 일.

8:36자리 정리

IDE에는 지니, 옆 창에는 행크와 버디, 터미널에는 애니·토디·제리. 계획과 안내는 토비, 결정은 Owner.

9:04지니의 버튼이 없다

  • 내 요구 행크와 버디처럼 지니도 버튼으로 바로 누르게 해 달라.
  • AI의 답(토비): 나는 IDE 화면을 직접 바꿀 수 없다. IDE 안의 지니에게 맡기는 게 맞다.
  • 핵심 AI마다 손댈 수 있는 범위가 다르다. 정한 역할 배치는 Notion 기록에 남겨 다음 대화에서도 이어지게 한다.

10:00지니가 내장 버튼 켜기

  • 내가 한 일 다른 에이전트에게 물어 버튼이 IDE에 이미 내장된 기능이라는 것을 알고 지니에게 알려 줌.
  • AI가 한 일(지니): 설정을 켜고 창을 새로 고쳐(Reload Window) 오른쪽에 에이전트 버튼을 바로 보이게 함.
