⚠ 영상을 열면 먼저 화질을 1080p로 바꿔 주세요

화면을 녹화한 영상이라 YouTube가 자동으로 고르는 화질(720p 이하)에서는 글씨가 뭉개져 읽을 수 없습니다. 1080p로 바꾸면 글씨가 또렷하게 보입니다.

화질 바꾸는 방법 (눌러서 보기)
  1. 컴퓨터: 영상을 재생하고 화면 오른쪽 아래 ⚙ 설정 → 화질 → 1080p HD를 누릅니다. 화질 옆에 "자동 (720p)"처럼 보이면 아직 바꾸지 않은 것입니다.
  2. 휴대폰 YouTube 앱: 영상 화면을 한 번 누르고 위쪽 ⚙ → 화질 → 고급 → 1080p를 고릅니다.
  3. 가능하면 전체 화면으로 보세요. 작은 창에서는 글씨가 더 작아집니다.

10:01▶ 영상 보기

바이브코딩 작업장은 폴더를 복사해 붙여 넣는 것으로 옮겨지지 않습니다. 노트북에서 쓰던 "토니의 지식 도서관"을 데스크톱으로 옮기며, 코드는 GitHub로 받고 GitHub에 없는 설정·데이터는 직접 옮기고 도구 설치부터 순서대로 확인합니다. 순서를 짜고 오류를 풀어 준 것은 Claude, 사람은 붙여 넣고 로그인하고 결정만 합니다. 중간에는 이 도서관이 영상 주소 하나로 스크립트를 읽고 Vertex AI로 요약해 웹페이지를 만드는 "에이전트 안의 에이전트" 구조도 소개합니다.

0:00이사 순서 받기

Claude가 7단계로 정리. Git, Python 설치 명령을 PowerShell에 붙여 넣음.

  • 알아 두면 좋은 말 PowerShell은 Windows에서 글자로 명령을 치는 창. Git은 파일 변경 기록을 관리하는 도구.

1:12Github에서 내려받고 비공개 파일 풀기

Github에 올리지 않는 설정·데이터 파일은 압축 파일로 옮김. Claude가 파일이 다 왔는지 확인하고, 줄 바꿈 방식만 달라진 파일을 원래대로 되돌림.

2:36부품 설치와 Google Cloud 도구

영상 요약에 Gemini를 쓰려면 Google 인증이 필요. 설치 후 빨간 오류가 나자, Claude는 Windows가 스크립트 실행을 막아 둔 것(실행 정책)이라며 내 계정에서만 허용하는 명령을 줌.

4:36데스크톱에서 도서관 열기

서버를 띄우자 노트북과 같은 도서관이 열림.

5:45에이전트 안의 에이전트 (핵심 장면 ①)

  • 영상 주소를 넣고 시작을 누르면: 프로그램이 자막과 시간 표시를 읽어 전체 스크립트를 파일 하나로 저장 → Vertex AI가 시간 표시 기준으로 같은 주제끼리 묶어 구간별 요약 → 전체를 다시 읽고 핵심 정리, 분야·태그 같은 메타데이터까지 채워 저장 → 자동화 프로그램이 저장된 결과로 웹페이지를 보여 줌.
  • 세 겹 구조: 나만의 코딩 에이전트(내 의도대로 코딩) → 그 도움으로 만든 자동화 에이전트 → 그 안에서 일하는 AI(Vertex AI).
  • 알아 두면 좋은 말 에이전틱 AI는 판단은 AI가, 반복은 프로그램이 맡아 사람 없이도 일을 이어 가는 방식.

6:48공개 사이트 게시 실패 (핵심 장면 ②)

  • 원인 노트북과 데스크톱의 게시 기록이 서로 엇갈림.
  • AI가 한 일 Github의 공개 사이트 기록을 받아 맞추는 명령 제시. 대기 시간이 길어진 이유(실패할 때마다 두 배로 늘리는 규칙)는 요구 사항이 아니라 코드를 만든 에이전트가 정한 것이라고 짚고, 최대 대기 시간을 줄이자고 제안.
  • 내가 정한 것 앞으로 영상 게시는 데스크톱 한 곳에서만.

9:18작업장 이사 3원칙

코드는 GitHub로 받고, GitHub에 없는 설정·데이터는 직접 옮기고, 도구 설치부터 순서대로 확인한다. 같은 방법으로 사진 중복 정리나 영상 분류도 할 수 있다.
