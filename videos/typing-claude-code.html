⚠ 영상을 열면 먼저 화질을 1080p로 바꿔 주세요

화면을 녹화한 영상이라 YouTube가 자동으로 고르는 화질(720p 이하)에서는 글씨가 뭉개져 읽을 수 없습니다. 1080p로 바꾸면 글씨가 또렷하게 보입니다.

화질 바꾸는 방법 (눌러서 보기)
  1. 컴퓨터: 영상을 재생하고 화면 오른쪽 아래 ⚙ 설정 → 화질 → 1080p HD를 누릅니다. 화질 옆에 "자동 (720p)"처럼 보이면 아직 바꾸지 않은 것입니다.
  2. 휴대폰 YouTube 앱: 영상 화면을 한 번 누르고 위쪽 ⚙ → 화질 → 고급 → 1080p를 고릅니다.
  3. 가능하면 전체 화면으로 보세요. 작은 창에서는 글씨가 더 작아집니다.

② Claude Code

14:14▶ 영상 보기

바이브 코딩으로 한글타자연습앱을 만드는 세 편 중 두 번째. 같은 요구 사항으로 AI Studio의 Playground에서 만든 HTML 파일 하나를 Claude Code에게 맡겨, 기능별 파일로 나누고 Github Pages에 배포한 뒤 Firebase로 Google 로그인과 순위표까지 붙여 수업용 사이트로 만든다.

이 편의 출발점

  • 출발점: 같은 요구 사항으로 Google AI Studio의 Playground에서 만들어 내려받은 HTML 파일 하나(원본 앱 열어 보기).
  • 요구 사항 문서: project-intent.md. Owner의 의도와 MVP 범위, 구현·검수 기준을 적은 문서.
  • 일한 곳: 내 컴퓨터의 폴더. Claude 데스크톱 앱의 Claude Code가 파일을 직접 고치고 명령을 실행한다.
  • 이 편의 특징: Github 설정은 Claude in Chrome으로 내 브라우저를 조작해 처리했고, 음악 변환 프로그램 설치처럼 내 컴퓨터에서 하는 일도 Claude Code가 직접 했다.

장면별 자세한 설명

0:00소개

  • 완성된 앱 화면 위에 제목이 나오고, 이 편에서 무엇을 하는지 먼저 설명한다.

0:26Playground 앱을 Claude Code에게 맡기기

  • 내 요구 AI Studio Playground에서 만든 한 파일짜리 앱을 기능별로 나누고 Github에 배포해 달라.
  • AI가 한 일 한글 글쇠 위치를 손가락별로 익히는 원래 앱을 화면·자판·연습 세트·언어 파일로 나누고, 연습 기록 저장과 배경 음악 기능을 붙임.
  • 알아 두면 좋은 말 Claude Code는 내 컴퓨터의 폴더를 열어 파일을 직접 만들고 고치고 명령까지 실행하는 코딩 AI.

1:01기록 저장과 세 가지 언어 화면

  • 연습을 마치면 날짜·시간이 들어간 이름으로 기록 파일이 저장되는지 직접 시험. 베트남어·미얀마어로 바꿔 보며 세 언어가 같은 모양인지 확인하고, 제목·언어 버튼·로그인 버튼을 두 줄로 정리.

2:02사이트가 안 열린다: 비공개 저장소 문제

  • 원인 무료 계정은 비공개 저장소에서 Github Pages를 쓸 수 없음. 저장소를 공개로 바꿔야 함.
  • 알아 두면 좋은 말 Github Pages는 Github 저장소의 파일을 그대로 웹사이트로 열어 주는 무료 서비스.

2:38Claude in Chrome으로 Github 설정하기 (핵심 장면 ①)

  • AI의 답 저장소 설정을 바꾸려면 Github 로그인이 필요하니 Chrome 확장 프로그램을 쓰자.
  • 내가 한 일 Github 로그인.
  • AI가 한 일 내 Chrome을 대신 조작해 저장소를 공개로 바꾸는 확인 창을 띄우고 Pages 배포 설정까지 진행.
  • 알아 두면 좋은 말 Claude in Chrome은 내 Chrome 브라우저를 Claude가 대신 클릭하고 입력하게 해 주는 도구. 로그인은 사람이 한다.

4:14Firebase로 Google 로그인과 데이터베이스 (핵심 장면 ②)

  • 내 요구 학생 기록을 모으고 순위표를 보여 주고 싶다.
  • AI가 한 일 Firebase 프로젝트를 만들고 웹 앱을 등록. Google 로그인을 켜고, 기록을 저장할 Firestore를 만들고, 다른 사람이 기록을 함부로 고치지 못하게 보안 규칙까지 적용. 순위표 페이지와 Readme도 정리해 Github에 올림.
  • 알아 두면 좋은 말
    • Firebase: Google의 앱 뒷단 서비스. 서버를 직접 만들지 않아도 로그인과 데이터 저장을 쓸 수 있음.
    • Authentication: "누가 들어왔는지" 확인하는 로그인 장치.
    • Firestore: 학생별 연습 기록을 모아 두는 인터넷 저장소.
    • 보안 규칙: 학생은 자기 기록만 쓰고, 남의 기록은 고치지 못하게 막는 약속.
  • 왜 대단한가 사람이 하면 Firebase 사이트에서 프로젝트 만들기, 로그인 켜기, 설정값을 코드에 옮기기, 규칙 쓰기를 하나씩 해야 하는 일. 사람은 로그인 같은 단계만 직접 했다.

6:26실제 사이트에서 연습해 보기

  • 자리 연습 세트를 차례로 쳐 봄. 화면 아래 자판에 눌러야 할 글쇠와 손가락이 함께 표시되고, 연습을 마치면 기록이 파일로 저장됨.

7:50오른쪽 Shift 문제 고치기

  • 증상 오른쪽 Shift를 눌러도 화면에서 반응하지 않음.
  • AI가 한 일 왼쪽과 오른쪽 Shift를 구분하도록 고치고, 로그인했을 때 별명과 로그아웃 버튼이 따로 보이게 화면을 다듬음. 학생 40명이 함께 써도 Firebase 무료 요금제 안이라는 설명도 함께.

9:14음악 파일을 MP3로 줄이기

  • 내 요구 원본 음악 파일이 너무 크다. 변환 프로그램을 설치해 달라.
  • AI가 한 일 변환 프로그램을 직접 설치하고 네 곡을 약 10분의 1 크기로 줄여 다시 배포. 완료한 기능을 표로 정리.

10:38학생용 짧은 주소 만들기

  • 학교 이름을 넣은 주소를 추천받고 이미 쓰는 이름은 피해서 고름. 한 서비스는 중간 확인 화면이 나와서 바로 연결되는 다른 서비스로 다시 만들고, 왜 차이가 나는지 설명받음.

12:14AI Studio에서도 만들 수 있을까

  • 같은 앱을 AI Studio에서도 만들 수 있는지, 음악·로그인·데이터베이스는 어떻게 되는지 정리. Claude Code는 내 컴퓨터에서 직접 일하고, AI Studio는 Google 클라우드 안에서 만든다는 차이.
