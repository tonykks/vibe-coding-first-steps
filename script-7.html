덧붙임 — 회사 컴퓨터 안에서 AI 쓰기

1 · 데이터의 길

업무에 쓰기 전에 데이터의 길을 나눕니다

회사 내부 자료나 개인정보를 코딩 에이전트가 직접 읽게 하면, 사용하는 제품과 계약과 설정에 따라 그 데이터가 외부 AI 서버로 보내질 수 있습니다. 3부에서 본 것처럼, 에이전트가 내 컴퓨터 폴더에서 일해도 생각하는 두뇌(모델)는 클라우드에 있기 때문입니다.

그래서 오늘의 사례들도 업무 데이터 대신 가상 데이터와 제 개인 취미 자료로 만들었습니다. 업무에 적용하기 전에 두 가지를 나누어 보십시오. 하나는 가상 데이터로 프로그램을 개발하는 길입니다. 다른 하나는 완성된 프로그램이 실제 데이터를 처리하는 경우와, AI가 실제 데이터를 직접 읽는 경우의 차이입니다. 실제 데이터는 완성된 프로그램이 처리하게 하고, AI는 가상 데이터로 개발하게 하는 길이 가장 안전합니다.

2 · 로컬 AI

두뇌까지 내 컴퓨터 안으로 — LM Studio와 Cline

그래도 AI가 실제 데이터를 봐야 하는 일이 있습니다. 기밀 문서를 클라우드에 올리기 어려운 회사나 개인이라면, AI의 두뇌까지 내 컴퓨터 안으로 들여오는 방법이 있습니다. 순서는 네 단계입니다.

  1. LM Studio 설치: 내 컴퓨터에서 AI 모델을 내려받아 돌리는 무료 프로그램입니다.
  2. 모델 받기: LM Studio 안에서 공개 모델 저장소인 Hugging Face의 모델을 고릅니다. 내 컴퓨터의 그래픽카드와 메모리에 맞는 크기여야 합니다. 큰 모델일수록 똑똑하지만 더 좋은 사양이 필요합니다.
  3. Cline 설치: Antigravity IDE에 코딩 에이전트 확장인 Cline을 설치합니다.
  4. 연결: Cline의 설정에서 두뇌를 클라우드 모델 대신 LM Studio에서 돌리는 내 컴퓨터의 모델로 정합니다.

이렇게 하면 두뇌와 손발과 작업 공간이 모두 내 컴퓨터 안에 있습니다. 데이터가 회사 밖으로 나가지 않는 방식으로 AI를 쓸 수 있습니다.

다만 알아 두실 것이 있습니다. 내 컴퓨터에서 돌리는 모델은 사양에 따라 속도와 성능이 크게 다릅니다. 클라우드의 큰 모델만큼 해내기를 기대하기는 어렵습니다. 그리고 프로그램을 설치하기 전에 회사의 보안 규정을 먼저 확인하십시오. 오늘은 이런 길이 있다는 것을 안내해 드리는 정도로 하겠습니다.
