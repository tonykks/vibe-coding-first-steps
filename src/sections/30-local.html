3부 · 01 채팅창에서 시작

"10분 타이머 만들어 줘" — 한 문장이면 어느 AI든 만들어 줍니다

10분 타이머→큰 숫자→검은 바탕·노란 숫자→마지막 10초 빨간색→1·5·10·20분→알림음→계절 그림 배경
  • 같은 말을 일곱 곳에 넣음. ChatGPT 채팅·Work·Codex, Claude 채팅·Code, Gemini, Google AI Studio Playground·Build mode
  • 어느 곳이든 한 줄만 넣어도 돌아가는 타이머를 만들어 줌. 시작·일시정지·알림음처럼 말하지 않은 것까지 넣음
  • 숫자 크기와 색, 시간 버튼, 계절 그림 배경도 말로 더하는 대로 다 만들어 줌
  • 코드를 전혀 몰라도, 원하는 것을 정확하게 말하면 다 만들어 줌
같은 타이머, 일곱 가지 AI

이제는 어느 AI든, 늘 쓰던 창에서 말로 하면 프로그램을 만들어 줍니다.

  • ChatGPT와 Claude는 쉬운 것은 채팅창, 복잡한 것은 코딩 전용 창으로 나뉘어 있어 내가 골라 들어감

어느 회사든 웹에서 바로 시작할 수 있습니다. 문제는 고치고 키울 때 드러납니다.

3부 · 04 웹의 구조

웹에서는 두뇌도, 손발도, 작업 공간도 모두 클라우드에 있습니다

두뇌는 AI 모델(LLM)

인터넷 너머 회사의 컴퓨터(클라우드)에서 생각함

손발은 도구

파일 만들기, 실행하기. 웹에서는 이것도 서비스 회사의 클라우드에 있음

작업 공간은 클라우드 안

결과물도 서비스 안의 가상 공간에 만들어짐

  • 채팅으로 시킨 프로그램은 클라우드에서 만들어지고, 웹 화면은 그것을 비춰 줄 뿐임
  • 그래서 고치려면 다시 말로 요구하고, AI가 클라우드에서 고쳐 다시 보여 줌

웹에서는 내가 말하고, AI가 클라우드 안에서 만듭니다. 내 컴퓨터에는 아직 아무것도 없습니다.

펼쳐 보기▸
LLM
대규모 언어 모델(Large Language Model). 글과 코드를 만들어 내는 AI 모델 자체입니다.
클라우드
내 책상 위 컴퓨터가 아니라 인터넷으로 연결된 서비스 회사의 컴퓨터를 빌려 쓰는 것입니다.
도구
AI 모델이 직접 파일을 만들거나 프로그램을 실행하는 것은 아닙니다. 모델이 판단하면, 서비스에 연결된 도구가 파일을 만들고 실행합니다. 모델과 도구는 따로입니다.

3부 · 05 웹의 벽

고칠 때마다 전체를 다시 쓰면, 수정이 쌓일수록 벽에 부딪힙니다

  1. 음악만 고쳐 달라 했는데, 잘 되던 로그인 창이 번쩍 떴다가 0.1초 만에 사라짐
  2. 웹 속 AI는 내 파일에 닿지 못해 내 컴퓨터의 음악·이미지를 다루기 어려움
  3. 미리보기와 배포는 달라서 미리보기에서 되던 앱이 배포하자 로그인이 안 되고 음악이 안 나옴
  4. GitHub 배포 설정, Firebase 승인 도메인 같은 코드 밖 설정은 웹 속 AI가 못 만짐
  5. 대화가 길어질수록 AI가 읽을 토큰과 맥락이 늘어 비용이 늘고 앞의 조건을 놓침

전체 다시 쓰기

전구 하나 갈려고 집 전체 배선을 다시 깔기

차이만 고치기(Diff Patch)

나간 전구 하나만 갈기. 내 컴퓨터의 파일이면 AI가 필요한 줄만 고침

3부 · 06 데스크톱 앱으로

두뇌는 그대로 클라우드

생각하는 AI 모델은 여전히 회사의 컴퓨터에 있음

손발은 내 컴퓨터의 앱 안

파일 읽기·쓰기, 명령 실행

작업 공간은 내 폴더

내가 허락한 폴더 안에서만 일함

  • ChatGPT 앱의 Codex, Claude 앱의 Code 탭(Claude Code). 웹과 같은 채팅창 모양이라 낯설지 않음

  • 말로 설명하기 어려우면 그 화면을 캡처하거나 오류 글을 복사해 붙여 넣으면 됨. AI가 알아듣고 고침
  • 한글타자연습앱 ②③이 이 길. ②는 웹에서 받은 HTML 한 장을, ③은 빈 폴더를 내 컴퓨터에서 키움

3부 · 07 되돌릴 수 있게

망가져도 어제로 돌아갈 수 있게 — Git과 GitHub

  • 망가지면 어제 상태로 되돌릴 수 있게 기록해 두는 것이 Git, 그 기록을 온라인에 두는 곳이 GitHub
  • "강의자료_최종, 강의자료_진짜최종"처럼 이름을 바꿔 보관하던 일을 자동으로 해 줌
  • GitHub에 올린 것은 GitHub Pages로 주소 하나에 내놓을 수도 있음
  • 명령어는 몰라도 됨. "지금 상태를 저장해 줘", "어제 상태로 되돌려 줘"라고 말하면 에이전트가 함

AI에게 많이 맡길수록, 되돌릴 수 있는 기록이 먼저입니다.

펼쳐 보기▸

바뀐 내용을 기록해 두는 것이 Git, 그 기록을 온라인에 저장하고 함께 일하게 해 주는 서비스가 GitHub입니다. 둘은 같은 것이 아닙니다.
