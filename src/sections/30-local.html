3부

웹에서 내 PC로, 그리고 IDE로

이미 웹에서 바이브코딩을 해 본 분들을, 내 컴퓨터의 데스크톱 앱과 IDE로 안내합니다.

3부 · 01 몇 마디로 시작한 바이브코딩

"10분 타이머 만들어 줘" — 한 문장이면 시작됩니다

10분 타이머→숫자를 크게→검은 바탕에 노란 숫자→마지막 10초는 빨간색→5분·20분도, 알림음도…
  • 써 보면서 새 요구가 계속 생김 = 반복 개발(작게 만들고 써 보고 고치기)
  • 그런데 배경음악을 넣었더니 일시정지가 고장, 고쳤더니 알림음이 사라짐 = 회귀 결함
  • 그래서 "만들어 줘"에서 "기존 기능은 그대로 두고 고쳐 줘, 고친 뒤 모두 검사해 줘"로 말이 바뀐다

프로그램을 만드는 것과, 원하는 프로그램을 제대로 완성하는 것은 다른 문제입니다.

펼쳐 보기▸
반복 개발
Iterative Development. 처음부터 모든 요구를 알 수 없으니, 작게 만들어 써 보고 문제를 찾아 고치기를 되풀이하는 방식입니다.
회귀 결함
Regression. 새것을 고쳤는데 멀쩡하던 옛 기능이 고장 나는 일. 기능들이 같은 정보(예: 남은 시간)를 함께 쓰기 때문에 생깁니다. 사람이 짤 때도 생기지만, AI는 한 번에 많이 고치니 확인하지 않으면 늦게 발견합니다.
테스트
시작·일시정지·재시작·종료 알림처럼 기능 하나하나가 제대로 되는지 확인하는 일입니다.

AI Studio

3부 · 03 웹의 벽

수정이 쌓이면 웹 환경의 한계가 먼저 보입니다

  1. 통째로 다시 쓰기: 두 줄만 고쳐 달라 해도 파일 전체를 다시 쓰다 이전 조건이 빠짐
  2. 내 파일에 닿지 못함: 내 컴퓨터의 음악·이미지를 다루기 어려움
  3. 미리보기 ≠ 배포: 미리보기에서 되던 앱이 배포하면 멈춤(음악 버튼 먹통, 로그인 창 0.1초)
  4. 코드 밖 설정: GitHub 배포 설정, Firebase 승인 도메인은 웹 속 AI가 못 만짐
  5. 토큰과 맥락: 대화가 길어질수록 읽을 양이 늘어 비용이 늘고 앞의 조건을 놓침

전체 다시 쓰기

전구 하나 갈려고 집 전체 배선을 다시 깔기

차이만 고치기(Diff Patch)

나간 전구 하나만 갈기 — 내 컴퓨터의 파일이면 AI가 필요한 줄만 고칩니다

웹은 가능성을 열어 주고, 내 컴퓨터는 통제권을 줍니다.

왜 웹에서 내 PC로 옮겨 가는가 — 채팅에서 IDE로 →

맥락(Context)
AI가 지금 작업을 이해하는 데 쓰는 앞의 대화와 정보. 한 번에 읽을 수 있는 양(컨텍스트 윈도우)에 한계가 있습니다.

3부 · 04 권하는 방식

처음 구조는 웹에서, 이후 수정은 내 컴퓨터에서

① 웹에서 요구사항으로 화면과 구조 만들기→② 내 컴퓨터로 내려받기→③ 데스크톱 앱의 Codex·Claude Code로 이어서 고치기
  • 단순하지 않은 일일수록 이 순서. 한두 번 쓰고 버릴 결과물은 웹(채팅창·AI Studio)으로 충분
  • 세 회사 모두 같은 길: OpenAI(ChatGPT·Codex), Google(Gemini·AI Studio·Antigravity), Anthropic(Claude·Claude Code)
  • 데스크톱 앱 = 웹과 IDE 사이의 다리. 웹과 같은 채팅창 모양으로 내 폴더 안의 파일을 직접 읽고 고친다
  • "현재 프로젝트를 보고 종료 알림음 부분만 고쳐 줘. 나머지는 그대로." — 이렇게 말할 수 있게 된다
관광대 강의 준비 ② Claude 데스크톱 앱 이해하기

클라우드에서는 빠르게 시작하고, 내 컴퓨터에서는 꾸준히 고치고 키웁니다.

펼쳐 보기▸
데스크톱 앱
내 컴퓨터에 설치해 쓰는 AI 앱. Claude 앱의 Code 탭(Claude Code), ChatGPT 앱의 Codex처럼, 내가 허락한 폴더의 파일을 직접 읽고 고치고 실행합니다.
Codex / Claude Code
OpenAI와 Anthropic의 코딩 에이전트. 웹에서도 쓰지만, 데스크톱 앱에서 쓰면 내 컴퓨터 폴더가 작업 공간이 됩니다.

제 경험: Claude Code에게 한 번 승인했더니 Firebase 로그인과 데이터베이스 설정을 숨 돌릴 틈 없이 끝냈습니다. 그 능력은 정말 상상을 넘었습니다.

Claude로 시작하는 바이브코딩 → ChatGPT Plus로 시작하는 바이브코딩 → Google 생태계 사용 설명서 → Claude 웹·앱 비교와 문맥 관리 → ChatGPT 웹·앱 비교와 문맥 관리 →

3부 · 05 구조 한 장

두뇌는 클라우드에, 손발은 앱에, 작업 공간은 내 폴더에

두뇌 — AI 모델(LLM)

인터넷 너머 회사의 컴퓨터(클라우드)에서 생각합니다.

손발 — 도구

파일 읽기·쓰기, 명령 실행. 앱 안에 들어 있습니다.

작업 공간 — 내 폴더

내가 허락한 폴더 안에서만 일합니다.

  • 웹 브라우저: 클라우드의 두뇌가 클라우드의 손발로 클라우드 안 가상 공간에 결과물을 만든다
  • 데스크톱 앱·IDE: 클라우드의 두뇌가 내 컴퓨터 폴더에 결과물을 만든다
  • 망가지면? 어제 상태로 되돌리는 기록 = Git, 그 기록을 온라인에 두는 곳 = GitHub

AI가 내 컴퓨터에서 일한다고 두뇌까지 내 컴퓨터에 있는 것은 아닙니다. (7부에서 두뇌까지 들여오는 방법을 봅니다)

펼쳐 보기▸
LLM
대규모 언어 모델(Large Language Model). 글과 코드를 만들어 내는 AI 모델 자체입니다.
클라우드
내 책상 위 컴퓨터가 아니라 인터넷으로 연결된 서비스 회사의 컴퓨터를 빌려 쓰는 것입니다.
Git과 GitHub
"강의자료_최종.hwp, 강의자료_진짜최종.hwp"처럼 파일 이름을 바꿔 가며 보관하던 일을, 바뀐 내용을 기록해 자동으로 해 주는 것이 Git입니다. GitHub는 그 기록을 온라인에 저장하고 함께 일하게 해 주는 서비스입니다. 둘은 같은 것이 아닙니다.

3부 · 06 IDE는 어렵지 않다

IDE는 이미 아는 프로그램 넷을 한곳에 모은 것입니다

IDE 화면이미 아는 것하는 일
왼쪽파일 탐색기프로젝트의 폴더와 파일 보기
가운데메모장파일(소스코드) 열어 보기·고치기
옆 대화창ChatGPT 채팅창AI 코딩 에이전트에게 우리말로 시키기
아래명령 프롬프트터미널: 문자로 명령을 내리고 결과 보기
  • 실제로 쓰는 것은 채팅창 하나. 나머지는 에이전트가 일하는 모습을 보는 곳
  • 대신 AI가 어느 폴더에 어떤 파일을 만드는지 눈으로 볼 수 있어 나쁘지 않다
  • Antigravity IDE의 기본 에이전트에게 시켜도 데스크톱 앱과 같은 결과를 얻는다
  • 요즘 흐름: IDE 안에 AI 대화창(Agent)을 넣는다 — VS Code(Copilot), Cursor, Antigravity(Gemini)

그런데 일이 더 커지면, 에이전트 하나로 충분할까요? → 4부

펼쳐 보기▸
IDE
통합 개발 환경(Integrated Development Environment). 프로그램을 만들고 파일을 관리하고 실행하고 오류를 보는 도구를 한곳에 모은 작업 공간입니다. VS Code, Cursor, Antigravity가 그 예입니다.
Antigravity IDE
구글이 내놓은 AI 에이전트 중심 IDE. 내 컴퓨터에 설치해 쓰고, 기본 AI 에이전트가 들어 있습니다.
VS Code와 Visual Studio
이름만 닮았습니다. Visual Studio는 Microsoft의 큰 유료 개발 도구(1997~)입니다. VS Code는 2015년 무료로 내놓은 가벼운 편집기입니다. Visual Studio의 기능을 덜어 낸 것이 아니라, 웹 브라우저에서 돌던 편집기(Monaco)를 데스크톱 앱으로 옮긴 프로그램입니다. Microsoft가 2018년 GitHub을 사들인 뒤, 2026년 무렵부터 VS Code를 새로 설치하면 GitHub의 AI인 Copilot 대화창이 기본으로 들어 있습니다. GitHub 계정으로 로그인하면 쓸 수 있고, 원하지 않으면 끌 수 있습니다.
IDE 안의 Agent 창
VS Code에는 Copilot, Cursor에는 자체 AI, Antigravity에는 Gemini 기반 기본 Agent가 들어 있습니다. 우리는 Antigravity를 바탕으로, 기본 Agent(지니) 옆에 확장 기능으로 Codex와 Claude Code 두 개를 더해 씁니다. → 4부 「앉는 자리」·「여섯 자리」
터미널
본래 중앙 컴퓨터에 연결된 끝단 장치(단말)에서 온 이름. 지금은 문자로 명령을 입력하고 결과를 보는 창입니다. 명령어를 외울 필요는 없습니다. 에이전트가 쓰고 실행합니다.

제 경험: 같은 Firebase 작업을 Antigravity에서 했을 때는 에이전트가 "이 부분은 직접 하셔야 합니다"라고 안내해 하나씩 해 보았습니다. 번거로웠지만 일이 어떻게 돌아가는지 몸으로 알게 되었습니다. Claude Code는 편리함을, IDE는 배움의 기회를 주었습니다.
