같은 Agent라도 Extension과 CLI는 서로 다른 작업 좌석이 됩니다

강연에서는 VS Code에 두 개의 Extension, Terminal에 두 개의 CLI를 배치한 예를 통해 한 Agent에게 모든 일을 몰아주지 않고 구현과 검증을 분담하는 구성을 설명합니다.

VS CodeExtension · 대화형 작업
Codex ExtensionEditor 문맥과 변경 내용을 보며 Owner와 대화역할 예시 · Orchestrator
Antigravity Extension별도의 관점으로 설계 또는 Review 수행역할 예시 · 설계 / Review
TerminalCLI · 독립 실행 작업
Codex CLI명확한 작업 지시를 받아 구현, Test, 수정 실행역할 예시 · 구현 담당
Antigravity CLI완성 Code와 Test 결과를 독립적으로 점검역할 예시 · 검증 담당
구분ExtensionCLI
작업 위치VS Code의 대화 Panel과 EditorVS Code 안의 Terminal
강점현재 화면, 파일 변경, Owner의 피드백을 보며 대화형으로 조정정해진 명령과 파일을 기준으로 구현·Test·검증을 독립적으로 실행
강연의 역할 예시기획 조정, Orchestration, 중간 Review구현 담당과 검증 담당을 분리하여 결과를 상호 확인
핵심 차이지능의 우열보다 Interface, 문맥, 권한, 작업 방식이 다르므로 서로 다른 좌석으로 활용할 수 있습니다.
