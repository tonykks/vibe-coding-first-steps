한도에 막히지 않고 Claude 오래 쓰기

Claude는 보낸 메시지 개수가 아니라 Claude가 읽고 쓴 양으로 사용량을 셉니다. 같은 질문이라도 긴 대화 끝에서 하면 더 많이 듭니다. 무엇이 사용량을 크게 쓰는지 알면 같은 요금제로 훨씬 오래 쓸 수 있습니다.

세션 한도 5시간마다 초기화

짧은 시간 안에 몰아서 쓰는 양을 막습니다. 남은 시간이 지나면 다시 채워집니다.

주간 한도 일주일마다 초기화

초기화 요일과 시각은 계정마다 정해져 있습니다. 예시 계정은 매주 수요일 오전 10시입니다.

웹데스크톱 앱모바일 앱Claude Code

어디서 쓰든 하나의 사용량 통에서 빠져나갑니다. 휴대폰에서 많이 쓰면 컴퓨터의 Claude Code도 그만큼 덜 쓸 수 있습니다.

01

한도는 어떻게 움직이나

두 한도는 따로 돌아갑니다. 세션에 여유가 있어도 주간 한도를 다 쓰면 기다려야 합니다.

구분초기화기억할 점
세션 한도5시간마다몰아 쓰기를 막는 짧은 시계
주간 한도계정마다 정해진 요일·시각Opus 모델 전용 막대와 그 밖의 모델 막대가 따로 있음
대화 길이 한도초기화 없음한 대화에 담을 수 있는 양. 가득 차면 앞부분을 요약하며 이어 가고, 이때 사용량이 더 듭니다

한도에 닿았을 때 고를 수 있는 길

  • 기다리기: 세션 또는 주간 초기화 시각까지 기다립니다. 추가 비용이 없습니다.
  • 사용량 크레딧: 유료 요금제에서 추가 사용량을 켜 두면 한도를 넘어도 이어서 쓸 수 있습니다. 쓴 만큼 비용이 나갑니다.
  • 요금제 올리기: Max 요금제는 Pro보다 세션당 5배 또는 20배를 씁니다.
02

실제로 겪은 경고

강연 보충자료를 만들면서 이틀 동안 한 대화를 길게 이어 간 날의 기록입니다.

경고 화면

주간 한도를 겨우 11% 쓴 시점에 “이 속도면 월요일 저녁에 다 쓴다”는 안내가 떴습니다. 많이 쓴 양보다 쓰는 속도를 보고 미리 알려 주는 경고입니다.

그 주에 어디서 썼나

작업형 72% 채팅 28%
작업형: 파일과 웹페이지를 만들고 저장소를 내려받는 일채팅: 묻고 답하는 대화
대화 횟수는 채팅이 훨씬 많았는데도 사용량은 작업형이 세 배 가까이 썼습니다. 결과물을 만드는 일이 비싸다는 것을 숫자로 확인한 사례입니다.
03

사용량을 많이 쓰는 순서

위에 있을수록 한 번에 크게 듭니다. 직접 써 보며 확인한 순서입니다.

  1. 긴 대화Claude는 답할 때마다 대화 전체를 처음부터 다시 읽습니다. 앞에서 올린 이미지도 매번 다시 읽습니다. 대화가 길어질수록 한 번 답하는 값이 커집니다.
  2. 작업형 일파일·웹페이지 만들기, 이미지 처리, GitHub 저장소 내려받기. 여러 단계를 스스로 실행하므로 한 번의 요청이 여러 번의 답과 같습니다.
  3. 큰 화면 전체 캡처이미지는 면적이 클수록 많이 듭니다. 모니터 전체를 찍으면 필요 없는 부분까지 값을 치릅니다.
  4. 이미 보낸 자료 다시 보내기같은 파일이나 긴 글을 다시 붙여넣으면 대화 안에 두 번 들어가 매번 두 번 읽힙니다.
  5. 높은 성능 모델과 깊은 사고 설정Opus 같은 상위 모델과 오래 생각하는 설정은 같은 질문에도 더 많이 씁니다.
04

절약하는 다섯 습관

03의 원인을 하나씩 막는 습관입니다. 결과물의 품질은 그대로 두고 낭비만 줄입니다.

1주제가 바뀌면 새 대화

긴 대화를 끊는 것이 가장 큰 절약입니다. 지금까지의 상태는 Notion 상태 페이지와 메모리에 남겨 두고, 새 대화 첫 줄에서 그 페이지를 읽게 합니다.

이렇게 하면 비쌉니다

이틀째 같은 대화에서 설정 이야기, 강연 이야기, 웹페이지 만들기를 이어서 함

이렇게 하면 아낍니다

“Notion의 「현재 상태」 페이지를 읽고 이어서 하자. 오늘은 새 자료를 만들고 싶어.”

2필요한 부분만 캡처

문제가 보이는 영역만 잘라 보냅니다. 왼쪽 사이드바의 다른 대화 제목처럼 보이면 안 되는 정보가 함께 찍히는 것도 막을 수 있습니다.

3같은 대화에서는 바꿀 곳만 말하기

비쌉니다

수정한 글 전체를 다시 붙여넣고 “이거 다시 봐 줘”

아낍니다

“앞의 03번 표에서 두 번째 줄만 이렇게 바꿔 줘”

4큰 결과물은 내용을 확정한 뒤 한 번에

웹페이지나 PPT를 만들어 놓고 내용을 여러 번 고치면 매번 큰 파일을 다시 만듭니다. 목차와 문장을 대화로 먼저 정한 다음 “이제 만들어 줘”로 한 번에 만듭니다. 여러 대화에서 반복해 쓰는 자료는 프로젝트 파일에 올려 두면 다시 읽을 때 덜 듭니다.

5사용량을 수시로 확인

02의 경고는 미리 알려 준 덕분에 대응할 수 있었습니다. 큰 작업을 시작하기 전과 끝낸 뒤에 한 번씩 확인하면 어떤 일이 얼마나 드는지 감이 생깁니다.

06

자주 묻는 것

강연에서 받을 만한 질문을 미리 정리했습니다.

질문답
커넥터를 연결하면 돈이 더 드나요?연결 자체에는 추가 요금이 없습니다. Notion이나 GitHub에서 내용을 읽어 올 때 그만큼 사용량이 듭니다.
PPT·Excel을 만들려면 Office가 필요한가요?필요 없습니다. Claude가 자기 작업 공간에서 파일을 직접 만들어 건네줍니다. 다만 작업형 일이라 사용량은 큰 편입니다.
한도가 차면 대화가 지워지나요?지워지지 않습니다. 초기화된 뒤 같은 대화에서 이어서 쓸 수 있습니다.
  • 주제가 바뀌면 새 대화를 열고 상태 페이지로 이었다
  • 캡처는 필요한 부분만 잘랐다
  • 큰 결과물은 내용을 정한 뒤 한 번에 만들었다
  • 큰 작업 전후로 사용량 화면을 확인했다
